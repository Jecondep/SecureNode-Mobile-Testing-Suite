# SecureNode Solutions - Testing Suite 🛡️

Proyecto de la Semana 14 enfocado en calidad de software y pruebas automatizadas.

## 🧪 Pruebas Implementadas
1. **Unitarias (Jest):** Validación de lógica de negocio y manejo de errores.
2. **Integración (Testing Library):** Conexión entre UI y Hooks de sensores.
3. **E2E (Maestro):** Flujo completo de seguridad en cámara.

## 🚀 Cómo ejecutar los tests
1. Instalar: `npm install`
2. Correr Unitarias e Integración: `npm test`
3. Correr E2E: `maestro test maestro/camera_flow.yaml`
