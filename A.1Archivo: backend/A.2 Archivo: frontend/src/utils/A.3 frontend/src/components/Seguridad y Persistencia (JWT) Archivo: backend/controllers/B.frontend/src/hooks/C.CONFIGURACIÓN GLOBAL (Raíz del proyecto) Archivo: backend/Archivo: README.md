# SecureNode Solutions
Proyecto de Aplicaciones Móviles - UEA

## Tecnologías
- React Native (Expo)
- Node.js & Express
- MySQL
- JWT para Seguridad
- Zod para Validaciones

## Cómo ejecutar
1. En `/backend`: `npm install` y luego `node server.js`
2. En `/frontend`: `npm install` y luego `npx expo start`
